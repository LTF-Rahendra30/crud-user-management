## A Simple User CRUD Management
##  Features
- Add user
- Edit user
- Delete user
## 🎯 Learning Objectives
Apa yang Anda ingin capai dari project ini:
- Menguasai DOM manipulation
- Memahami array methods (.map, .filter, .splice, dst)
- Event handling (click, submit, dst)
- State management sederhana

## 🚀 How to Run
1. Clone atau download repo ini
2. Buka `index.html` di browser
3. Mulai manage users!
